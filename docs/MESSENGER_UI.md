# Messenger UI

The floating messenger follows the deployed GadgetPoint Admin visual system:

- Primary blue: `#2377ff`
- Navigation/header navy: `#08111f`
- Workspace surface: `#f5f6f8`
- Borders: `#e4e7ec`
- Compact 6–8px radii instead of the older oversized WorkflowOS cards
- Bottom-right floating action on desktop; positioned above the mobile navigation bar on handheld devices
