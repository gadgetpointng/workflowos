# WorkflowOS messenger

The messenger is intentionally a compact extension of the existing communications system, not a second messaging backend.

## Owner

The floating blue message button opens an Admin-style composer over the current page. The owner can send a private message to one active staff member or publish to the team feed when the corresponding Owner Control is enabled.

## Staff

The same floating control opens Inbox. Staff do not receive owner-only directory or broadcast controls.

## Full workspace

`/owner-communications` remains the full communications workspace for history, read receipts and retraction workflows already supported by WorkflowOS.
