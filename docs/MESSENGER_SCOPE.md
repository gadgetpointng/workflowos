# Messenger scope

Included now: floating entry point, Admin-style inline owner composer, staff selection, private/team delivery, Owner Control enforcement, existing notification delivery and audit logging, staff Inbox entry point.

Not claimed as included yet: real-time threaded chat, typing indicators, attachments, reactions, voice notes, presence, or cross-device websocket synchronization. Those require a dedicated conversation/message data model and should be added as a separate reviewed phase.
